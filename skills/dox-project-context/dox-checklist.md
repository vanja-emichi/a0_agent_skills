# DOX Checklist

## Preflight

- [ ] Read root `AGENTS.md`.
- [ ] Identify every file or folder expected to change.
- [ ] Walk from project root to each target path.
- [ ] Read every `AGENTS.md` found along each route.
- [ ] Name the nearest local contract for each target area.
- [ ] Resolve conflicts by using the closer contract for local details without weakening parent DOX rules.

## During Work

- [ ] Keep edits inside the requested scope.
- [ ] Follow local ownership, workflow, output, and verification rules.
- [ ] Avoid stale or contradictory docs.
- [ ] Pass relevant DOX context to subordinates.

## Closeout

- [ ] Re-check changed paths against the DOX chain.
- [ ] Update nearest owning `AGENTS.md` if structure, contracts, workflows, outputs, or verification changed.
- [ ] Refresh affected Child DOX Indexes.
- [ ] Remove stale or contradictory text.
- [ ] Run relevant verification.
- [ ] Report docs intentionally left unchanged and why.
