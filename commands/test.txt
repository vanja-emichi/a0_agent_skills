## For new features (RED → GREEN → REFACTOR):

1. **RED** — Write tests that describe the expected behavior. They MUST FAIL.
2. **GREEN** — Implement the minimum code to make them pass.
3. **REFACTOR** — Clean up while keeping tests green.

## For bug fixes (Prove-It Pattern):

1. Write a test that reproduces the bug (it MUST FAIL)
2. Confirm the test fails — this proves the bug exists
3. Implement the fix
4. Confirm the test passes — this proves the fix works
5. Run the full test suite for regressions

You MUST NOT skip the failing-test step. A test that passes immediately proves nothing.
