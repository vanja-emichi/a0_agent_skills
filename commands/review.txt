3. **Architecture** — Follows existing patterns? Clean boundaries? Right abstraction level?
4. **Security** — Input validated? Secrets safe? Auth checked? (Also reference `security-and-hardening` skill)
5. **Performance** — No N+1 queries? No unbounded ops? (Also reference `performance-optimization` skill)

The reviewer MUST categorize findings as Critical, Important, or Suggestion.
